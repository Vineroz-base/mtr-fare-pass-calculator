# 港鐵車費及全月通計算機

[English](README.md) | 繁體中文（香港）

一個簡單、以瀏覽器運行的工具，幫助香港乘客了解**港鐵全月通（Monthly Pass Extra）**如何影響其行程車費。

---

## 🎯 功能簡介

在港鐵網絡中選擇任意兩個車站，計算機會將標準車費與五個全月通區域中較便宜的結果作比較：

- 一律顯示**標準車費**，
- 以橫行顯示各款全月通的優惠，並以直欄顯示不出閘／出閘再入閘的選擇，
- 在手機螢幕上改為可展開的逐款全月通車費卡片，
- 當不同全月通或再入閘車站的車費結果相同時會將它們歸組，而歸組的再入閘車站會共用一份車費明細，以及
- 在每個優惠車費旁顯示節省金額。

計算機會套用所有全月通規則：

- 在全月通區域內無限次乘車，
- 區域以外可享 25% 車費折扣，
- 將不出閘車費與沿途全月通涵蓋車站的同站出閘再入閘方案作比較，
- 只顯示比標準車費便宜的全月通及出閘再入閘結果，並在每個車費旁顯示節省金額，
- 在滑鼠懸停、聚焦或點擊時顯示各再入閘方案的折扣路段計算，
- 預設顯示轉乘次數最少的路線，並在選取車費結果欄標題時，提供經過車站最少的路線作為次選，
- 搜尋路線時考慮東鐵綫在上水的分支，以及將軍澳綫在將軍澳的分支，
- 將中環及香港視為同一車費邊界，並在路線中包括兩站收費區內的步行轉乘，
- 即使行程以全月通邊界車站為起點或終點，亦會比較適用範圍內的轉乘車站，
- 不包括某些路綫／車站（機場快線、羅湖、落馬洲、賽馬場、頭等車廂），
- 並使用 DATA.GOV.HK 的官方車費表。

---

## 🧰 特色

- 設有**起點**及**終點**下拉選單。
- 以顏色區分的切換按鈕，讓你選擇要比較哪些全月通結果，並設有全選切換。
- 即時車費計算及明細。
- 無需後端——一切在瀏覽器內運行。
- 寄存於 GitHub Pages，方便複製或修改。

---

## 📂 資料

車費資料以 JSON 嵌入，直接取自政府數據集。
全月通涵蓋範圍及折扣規則則以 JavaScript 實現。

---

## 🚀 使用方法

1. 在瀏覽器開啟 `index.html`，或前往 GitHub Pages 網站。
2. 選擇出發及抵達車站。
3. 使用以顏色區分的切換按鈕，選擇要比較五款全月通中的哪幾款——你無需只揀選單一款全月通。結果會即時更新。
4. 閱讀結果：每款已選全月通佔一行，每個不出閘／出閘再入閘選擇佔一欄。在手機上，可展開各款全月通卡片查看車費。

- **HTML / CSS / 純 JavaScript**

- 無需建置——直接開啟網頁即可

## 📌 備註及限制

- 不能取代港鐵官方計算機，僅供快速比較之用。
- 尚未包括輕鐵、接駁巴士及其他交通工具。
- 車費數據集有時可能需要手動更新。
